## Role and dates

I worked at Magnus as a **full-time Machine Learning Engineer from May 2023 to July 2024**.

## Contribution

The company developed LLM applications for clinical simulations/medical training and survey-feedback analysis. My main contribution was integrating Azure OpenAI, testing and iterating on prompts, and building retrieval-augmented generation so responses could use relevant source information.

Existing project records also describe FAISS/PostgreSQL vector retrieval, embedding comparisons, Flask APIs and asynchronous inference/summarization services. These were collaborative systems; this case does not claim sole authorship of the full products.

## Evidence and limits

## Skills

Azure OpenAI, prompt design and evaluation, RAG, vector retrieval, Python APIs and collaboration on domain-specific LLM applications.
